# TFM-PREDICCI-N-DE-LA-EVOLUCI-N-Y-FUTURO-DEL-SISTEMA-FERROVIARIO-DE-ALTA-VELOCIDAD-EN-ESPA-A.
Código en R y datos para el TFM: PREDICCIÓN DE LA EVOLUCIÓN Y FUTURO DEL SISTEMA FERROVIARIO DE ALTA VELOCIDAD EN ESPAÑA: UN ANÁLISIS DE SERIES TEMPORALES Y MACHINE LEARNING.

Código en R empleado para el análisis exploratorio de datos, el desarrollo de los modelos (Holt-Winters, SARIMA, SARIMAX, Prophet, XGBoost, MLP, NNAR y modelo híbrido CEEMDAN+XGBoost), validación cruzada expansiva, análisis de interpretabilidad y predicción final con el modelo SARIMAX.

Librerías necesarias para la ejecución del código:
forecast, prophet,rlang, ggcorrplot, lubridate, ggplot2, zoo, gridExtra, tidyr, caret, nnet, Rcpp,readxl, strucchange, kernelshap, shapviz, tseries, dplyr, xgboost, Rlibeemd, lmtest, patchwork y car
